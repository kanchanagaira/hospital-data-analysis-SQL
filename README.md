Hospital  Data Analysis – SQL Project

This project focuses on analyzing hospital data using PostgreSQL and SQL. The dataset contains information about hospitals, locations, departments, doctors, patients, admission and discharge dates, and medical expenses.

The project demonstrates how SQL can be used to extract meaningful insights from healthcare data through aggregation, grouping, sorting, date calculations, and analytical queries.

 📊 Key Analysis Performed

 Total patients treated per city
 Total patients by hospital department
 Hospital with the highest medical expenses
 Average medical expenses per day for each hospital
 Hospital with the maximum total patient stay
 Longest patient stay analysis
 Average patient stay by department
 Department with the least number of patients
 Monthly medical expenses report
 Hospital and department-level patient analysis

🎯 Project Objective

The objective of this project is to practice SQL-based data analysis and understand how structured healthcare data can be transformed into useful insights for reporting and decision-making.
